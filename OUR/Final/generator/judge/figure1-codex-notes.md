2. **The one sentence**

   “One command starts the course software on my laptop; I use it through a browser, and my work stays safely in my own folder.”

3. **Proposed architecture figure**

   Use **four boxes total**, counting the enclosing laptop boundary:

   | Box | Exact title | Exact subtitle |
   |---|---|---|
   | Outer boundary | **Your own laptop** | Works offline after the first download |
   | Course package | **Ready-made course software** | Editor and course tools with the instructor’s versions and settings |
   | Browser | **Web browser tab** | See and use the programming editor here |
   | Files | **Your coursework folder** | Files stay here even after the package is deleted |

   **Layout:** The laptop boundary encloses everything. Put the course package at upper left and the browser at upper right. Give the package about three fifths of the upper row’s width and emphasise it with a red border and bold title. Put the coursework folder beneath both, spanning most of the width. Use large text and generous space between boxes.

   **Connectors:**

   - A short arrow from an unboxed starting point inside the laptop boundary into the course package: **“Run one command to start”**.
   - An arrow from the course package to the browser: **“Shows the editor”**.
   - A two-way arrow between the course package and coursework folder: **“Reads and saves your work”**.

   **Caption:** “The course software runs on your laptop, appears in your browser, and saves coursework in your own folder. No server is involved.”
